# Triage labels

This table maps the five triage roles to GitHub labels. Use this mapping when an engineering skill refers to a triage role.

| Label in mattpocock/skills | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an unattended agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be acted on. |

To change the label vocabulary, edit the GitHub label column and keep the tracker labels consistent with it.
