调整布局

选择左侧方案。拖动模块标题移动，拖动右下角缩放。右侧可输入精确尺寸。取消模块勾选可隐藏，再次勾选可恢复。

选中模块标题后，用方向键移动 1 px。按住 Shift 移动 8 px，按住 Alt 调整尺寸。用 ⌘ / Ctrl + Z 撤销。

预览与保存

预览模式隐藏编辑标记。所有设备按钮只显示模拟提示。页面未连接机器人，示例数值不会随真机变化。

布局自动保存在当前浏览器。导出 HTML 后，可在其他设备打开并继续编辑。导出 JSON 可保存多份布局。

设计取舍

坐标与夹爪是主操作区。辅助项收进细栏。滑块只修改目标值，执行目标统一模拟提交。停用机器人固定在底栏。

坐标滑块使用项目的演示范围，不代表真机限位。X 为 100–350 mm，Y 为 −150–150 mm，Z 为 0–150 mm，R 为 −90–90 deg。夹爪范围为 0–1000。

控制说明 · 原面板行为

坐标与回零

X、Y、Z 使用 mm，R 使用 deg。基坐标系与法兰：User=0，Tool=0。回零表示所有关节回到 0 deg。

键盘操作

W/S 伸缩，A/D 底座旋转，R/F 升降，Q/E 法兰旋转。Z/X 打开或关闭夹爪，Esc 停用机器人。

按住一个键移动，松开后请求停止。每次最多按住 5 秒，机械臂行程不超过 50 mm 或 10 deg。夹爪会完成当前小步。离开面板后，键盘控制关闭。

夹爪与同步

开度 0 表示关闭，1000 表示打开。USB 反馈与位置命令共用串行连接。首次位置移动会关闭 I/O 控制，力与速度保持不变。

仿真跟随真实机器人与夹爪的测量位置。停止同步与停用机器人是两个操作。

本页面仅供布局设计，按钮不会发送控制命令。
