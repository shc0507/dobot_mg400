# 网页面板

[返回项目首页](../README.md)

网页面板可直接控制 MG400 和 PGEA 夹爪，不依赖 Isaac Sim。
它使用 Python 3.11+ 标准库，提供真机控制和只读反馈。
网页通过 WebSocket 连接接收实时状态，并发送命令和按键。
真机控制模式支持键盘点动，所有模式均不更新 Isaac 场景。

## 使用前

服务默认使用真机控制模式。
启动服务和打开网页不会连接机械臂或发送动作。
使用前，关闭 Isaac 控制面板和其他控制程序。
多个程序查询控制器时，连接可能互相中断。

Isaac 面板和网页面板用文件锁限制真机连接，同一机械臂只允许一个面板连接。
网页的只读模式也使用此锁。
部署在容器和宿主机时，按 [面板连接锁](olares.md#面板连接锁) 配置共享目录。
此锁只协调本项目的面板，不能阻止 DobotStudio 或其他主机连接。

## 打开面板

### 使用 Olares 已部署的服务

保持 LarePass VPN 连接。
VPN 访问控制规则必须允许 TCP `8766`。
打开 [Olares 网页面板](http://100.64.0.1:8766/)。

若出现认证框，输入访问密钥，再点击 `Connect`。
访问密钥保存在宿主机 `/opt/mg400-web-control/.env`。
本机备份为 `work/.web-panel-token`，该文件不纳入 Git。
服务未启动时，参见 [服务配置](#服务配置)。

### 在本地启动

在能访问机械臂的主机进入项目目录，运行：

```sh
python3 apps/control_panel/server.py
```

在该主机打开 [本地网页面板](http://127.0.0.1:8766/)。
省略 `--mode` 时，服务使用 `robot` 模式。
机械臂地址默认取自 `config/robot.toml`，可用 `--robot-host` 指定。

## 控制机械臂

按以下顺序操作：

1. 点击 `Connect & take control`，等待实测坐标。
2. 点击 `Enable robot`，使能机械臂。
3. 使能完成后，点击 `Use actual`。
4. 修改 `Target` 中的 X/Y/Z（mm）和 R（度）。
5. 点击 `Execute targets`，等待到位确认。

`Use actual` 将实测坐标复制到目标。
坐标使用基座坐标系和法兰原点（`User=0,Tool=0`）。
滑块范围是实测值附近的调节区间，不是真机限位。
执行前，程序用控制器逆解和现有关节范围检查验证目标。

`Home` 将 J1–J4 移动到 0°。
直线运动使用 `SpeedL=1,AccL=1`，回零使用 `SpeedJ=5,AccJ=5`。

## 控制夹爪

夹爪使用同主机的 USB 采集程序。
采集程序必须带 `--commands`，且必须与网页服务共享单调时钟。
先按 [USB 接在 Olares](olares.md#usb-接在-olares) 安装并启动采集服务。
再启动网页服务，用 `--gripper-feedback` 指定采集文件。
以下示例使用 Isaac 容器内的数据路径：

```sh
python3 apps/control_panel/server.py --mode robot \
  --gripper-feedback /root/Documents/mg400-data/work/gripper_olares_feedback.json
```

`--gripper-feedback` 必须是网页进程可读的路径。
在 Olares 宿主机运行时，按 [USB 配置](olares.md#usb-接在-olares) 的 `hostPath` 映射改写路径。
网页服务不会自动启动采集程序或初始化夹爪。
没有夹爪反馈时，机械臂仍可单独控制。

夹持物体时不要初始化。
初始化会张开夹指寻找行程端点。
按以下顺序操作：

1. 未初始化时，点击 `Initialize gripper`。
2. 修改 `Gripper` 开口，0 表示闭合，1000 表示全开。
3. 点击 `Execute targets`。

机械臂到位确认后，服务才执行夹爪目标。
`Stop arm` 和下使能不会撤回已发送的夹爪命令。

## 键盘点动

键盘点动只在真机控制模式可用，运动规则同 [Isaac 键盘点动](isaacsim.md#键盘点动)。
使用键盘点动时，现场必须有人能操作物理急停。
W/S、A/D、R/F、Q/E 是连续点动（按住时持续运动，没有轨迹终点）。

按以下顺序操作：

1. 点击 `Connect & take control`，等待实测坐标。
2. 点击 `Enable robot`，等待使能完成。
3. 在 `Speed %` 输入 1–100 的整数，默认值为 1。
4. 点击 `Keyboard: OFF`。
5. 等待按钮显示 `Keyboard: ON N%`，N 是所选速度。
6. 按住一个按键点动，松开按键请求停止。

检查期间，按钮显示 `Keyboard: CHECKING…`。
服务设置所选 `SpeedFactor` 并核对速度反馈。
检查不发送运动命令。

`SpeedFactor` 是全局比例，也影响 `Home` 和 `Execute targets`。
关闭键盘控制后，服务不恢复原比例。
`Speed %` 的悬浮提示显示控制器当前比例。
修改速度前，先关闭键盘控制。
修改 `Speed %` 后，点击 `Keyboard: OFF` 应用新速度。

| 按键 | 动作 |
| --- | --- |
| W / S | 沿机械臂朝向伸出 / 收回 |
| A / D | J1 左转 / 右转 |
| R / F | 法兰上升 / 下降 |
| Q / E | J4 正转 / 反转 |
| Z / X | 夹爪开口增加 / 减少，每步 25 / 1000 |
| Esc | 下使能机械臂，仅在键盘控制开启或检查期间有效 |

键盘控制关闭后，Esc 无效。
此时点击 `Disable robot` 下使能。

W/S 按需改写控制器 User 8，关闭键盘控制后不恢复。
User 8 不得用于其他标定或程序。

Z/X 只在机械臂空闲时执行，每次长按最多 5 秒。
夹爪未初始化或反馈不可用时，服务只提示夹爪错误。
机械臂按键保持可用。

按住按键时，页面每 100 ms 经 WebSocket 连接重发当前按键。
服务 0.4 秒内未收到更新时，停止当前点动并关闭键盘控制。
网络延迟波动接近 0.4 秒时，点动可能因此中断。

服务检测到页面连接关闭时，立即关闭键盘控制。
网络中断时，服务可能检测不到连接关闭，由 0.4 秒按键超时停止点动。

页面失去焦点、隐藏、打开右键菜单、开始拖动或开始编辑输入框时，键盘控制关闭。
按下 Shift、Ctrl、Alt 或 Meta 时，键盘控制也关闭。
点击 `Home`、`Execute targets` 或 `Initialize gripper` 时，服务也关闭键盘控制。
机械臂离开使能空闲状态、反馈失效或报警、关节超出范围或夹爪锁定时，服务关闭键盘控制。
恢复点动前，再次点击 `Keyboard: OFF`。

机械臂点动期间按 Esc 或点击 `Stop arm`、`Disable robot`、`Disconnect` 时，服务先等待点动停止核验结束。
此等待最长约 12 秒。
核验失败或超时时，服务仍发送停止或下使能命令。
机械臂没有立即停止时，使用物理急停。

机械臂点动出现通信或状态异常时，服务停止并锁定控制。
停止已确认时，下使能确认后控制解锁。

Z/X 命令结果未知时，服务锁定夹爪并关闭键盘控制。
机械臂不因此停止。

夹爪锁定或停止未确认时，下使能不解除锁定。
核实机械臂和夹爪状态，再重启网页服务。
控制器报警导致的停止未确认按 [清除报警](#清除报警) 处理。
采集程序的命令锁按 [操作被拒绝或控制锁定](isaacsim.md#操作被拒绝或控制锁定) 处理。

## 停止与恢复

正常结束时，点击 `Disable robot`，再点击 `Disconnect`。
`Stop arm` 请求受控停止，不是物理急停。
若停止或命令结果无法确认，使用现场物理急停。

同一时刻只有一个页面持有控制权。
页面每 0.5 秒经 WebSocket 连接发送心跳。
页面关闭或 3 秒内未发出心跳时，服务请求停止机械臂并锁定控制。
服务或代理关闭连接后，页面自动重连。
页面 3 秒内重连成功时，保留控制权，键盘控制保持关闭。
网络中断超过 3 秒时，服务停止机械臂并锁定控制。

连接中断时，页面停用依赖连接的控制。
连接中断期间，页面每秒经 HTTP 读取一次状态。
没有读到时，页面保留最后收到的状态。
`Stop arm` 和 `Disable robot` 同时经 WebSocket 连接和单独的 HTTP 请求发送。
连接中断时，这两个按钮和 Esc 仍可用。

在服务终端按 Ctrl+C 或停止 systemd 服务时，服务先请求停止并等待确认。
之后服务退出。
等待期间，重复信号不会中断停止确认。

进程被强制结束、崩溃、断电或网络故障时，停止命令可能无法送达。
机械臂可能继续到有限轨迹的终点。
连续点动没有终点。
机械臂可能继续运动，直到控制器限位或碰撞。

已确认停止后，可下使能并重新使能。
未知命令结果不会因重新连接页面而解除锁定。
若断开时无法确认停止，面板停止常规坐标查询。
此时保留反馈、连接锁和安全警告，另一个面板不能接管。
不要删除锁文件来解除占用。
文件删除后，两个进程可能各自持锁。

### 清除报警

控制器报警时，`Mode` 显示 9，控制器拒绝下使能和停止命令。
报警会停止机械臂运动。
面板因停止未确认而锁定，并列出报警编号、说明和处理方法。
说明文字取自 Dobot 的报警表。

按以下顺序恢复：

1. 按报警的处理方法排除原因。
2. 点击 `Clear alarm`。
3. 等待面板提示报警已清除，并确认下使能和静止。

`Clear alarm` 只发送 `ClearError()`，不发送 `Continue()`。
报警前暂停的运动不会恢复。
报警清除后，服务在新的控制实例上下使能，并确认机械臂静止。
两项都确认后，控制解锁。

报警原因仍在时，报警会立即重新出现，面板保持锁定。
关节限位报警（例如 69、72）只在机械臂退回限位内后才能清除。
用 DobotStudio Pro 或示教器点动退回。
点动退回后，按 [从服务器切换 TCP/IP 模式](hardware.md#从服务器切换-tcpip-模式) 核对控制器模式。

碰撞检测触发时，报警列表显示 `-2`（Collision detected）。
报警在面板外清除时（例如用机械臂上的 Collision Resume 键），按钮显示 `Recover`。
核实机械臂状态后，点击 `Recover`。
服务在新的控制实例上下使能并确认静止，确认后解锁控制。
只有报警期间发生的停止未确认才能用 `Recover` 恢复。

命令顺序未知时，报警清除后控制仍保持锁定。
无报警时发生的停止未确认也保持锁定。
核实机械臂状态，再重启网页服务。
恢复期间点击 `Stop arm` 且停止未确认时，控制也保持锁定。
停止未确认期间，状态栏提示恢复方法，之后的成功停止不覆盖此提示。

## 只读反馈

只读模式使用以下命令：

```sh
python3 apps/control_panel/server.py --mode read-only --robot-host 192.168.1.6
```

点击 `Start sync` 才连接 TCP `30004`，`Stop sync` 停止读取。
此模式只显示实测关节、控制器模式和报警标志。
它不提供坐标或夹爪反馈。

## 服务配置

Olares 部署目录为 `/opt/mg400-web-control`。
`mg400-web-panel.service` 使用宿主机 Python 3.12。
在 Olares 宿主机启动或检查服务：

```sh
sudo systemctl start mg400-web-panel.service
sudo systemctl status mg400-web-panel.service --no-pager
```

停止服务时，面板最长用约 60 秒确认机械臂停止。
`TimeoutStopSec` 必须大于此时间，systemd 默认值 90 秒满足要求。

服务默认监听 `127.0.0.1:8766`，可用 `--bind` 和 `--port` 修改。
监听非回环地址时，必须设置至少 24 个字符的 `MG400_PANEL_TOKEN` 环境变量。
访问密钥只能包含可打印 ASCII 字符，不得以空格开头或结尾。
网页使用同一密钥访问 API。
未设置访问密钥时，在浏览器打开 `127.0.0.1`、`localhost` 或 `[::1]` 地址。
服务拒绝其他主机名。

反向代理保留路径前缀时，可加 `--base-path /mg400-panel/`。
网页和 API 均使用此前缀。
反向代理必须满足以下要求：

- 用 HTTP/1.1 转发 `api/ws`，并转发 `Upgrade` 和 `Connection` 请求头。
- 保留浏览器发送的 `Host` 值（含端口），或在 `X-Forwarded-Host` 中传递该值。nginx 用 `$http_host`，不用 `$host`。
- 读取超时大于 5 秒。服务每秒至少推送一次状态，每 5 秒发送一次 ping。
- 服务监听回环地址时，也设置 `MG400_PANEL_TOKEN`。

接口说明见 [机器人服务接口](development.md#机器人服务接口)。

更新服务代码时，将 `apps/` 和 `src/` 更新到同一提交，再重启服务。
`server.py` 依赖 `src/mg400_agent/` 中的模块。
重启后，必须重新加载已打开的面板页面。
页面的消息格式版本与服务不一致时，页面提示重新加载，不再重连。
版本相同的旧页面不提示。
