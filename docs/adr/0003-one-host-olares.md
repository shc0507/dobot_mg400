# 0003：统一使用 Olares 主机

## 状态

已接受：2026-10-30。

## 背景

实验室设备使用独立的应用环境。集中服务后，必须保持设备身份稳定并控制访问权限。

## 决定

将全部实验室设备连接到 Olares，并在该主机运行服务。每台设备由 1 个服务管理。服务端口如下：

| 服务 | 端口 |
| --- | --- |
| 机械臂面板 | 8766 |
| 位移台面板 | 8767 |
| 摄像头预览 / go2rtc | 1985 / 1984。go2rtc 仅绑定回环地址 |
| 热成像 / 炉子 / 显微镜 | 8768 / 8769 / 8770 |
| 视觉 | 8771，回环地址 |
| 编排器与仪表盘 | 8772 |
| 智能体网关 | 8773，回环地址 |

- 配置存于 `/etc/mg400/mg400.env`。服务读取 `<PREFIX>BIND`、`<PREFIX>PORT` 和 `<PREFIX>TOKEN`。代码和单元文件不得包含特定主机的地址或路径。
- `MG400_OPTIONAL_SERVICES` 选择可选服务。安装器仅准备选中的服务。多数服务使用 `/opt/mg400/.venv`，视觉使用 `/opt/mg400/.venv-vision`。
- 模型、校准、示教工位、工具偏移、位移台配置、热成像区域、炉子状态、运行记录和录像均存于 `/var/lib/mg400`。
- 数据所有者为 `1000:1000`，目录权限为 `0750`，文件权限为 `0640` 或 `0600`。安装器创建数据目录。
- USB 清单记录设备名称、VID:PID、稳定路径、集线器及端口和服务。设备身份使用 `/dev/serial/by-id/` 和 `/dev/v4l/by-path/`。
- Toupcam 摄像头独占一个 USB 3 控制器。按用途配置有源集线器。不得重置共用的上游集线器。
- 渲染已启用服务的 udev 模板，填写 VID/PID 和 `MODE="0660"`。将 `@SERVICE_GROUP@` 替换为 GID 1000 的组名。以 root 和权限 `0644` 安装 `/etc/udev/rules.d/70-mg400-<name>.rules`。重新载入规则并触发 USB 枚举。

硬件冻结持续到所有者解除为止。清点和软件工作可以继续。设备搬移、接线和安装固定必须等待。

## 影响

Olares 成为统一运行主机。USB 拓扑和稳定路径成为部署要求。软件不能替代急停链路或独立超温切断装置。
