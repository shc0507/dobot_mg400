# 交互终端

[返回项目首页](../README.md)

交互终端直接控制 MG400 和真空吸盘。
界面持续显示反馈，在底部输入命令。
它不依赖 HTTP 服务。
终端不能检测松键，不支持键盘点动。

## 启动

在能连接机械臂的主机运行终端。
程序使用 Python 3.12+ 标准库中的 `curses`。
支持 macOS、Linux 本地终端和带 PTY 的 SSH 会话。
PTY 是 SSH 分配的交互终端，可用 `ssh -t` 请求。

使用前，关闭其他机械臂控制程序。
终端与机器人服务共用机械臂连接锁。
多个进程必须配置相同的机械臂地址。
锁目录固定为 `/var/lib/mg400/locks`。
目录和权限要求见 [面板连接锁](deploy.md#面板连接锁)。
此锁不能阻止 DobotStudio 或其他主机连接。

在按 [主机部署](deploy.md) 安装的主机上运行：

```sh
sudo labctl terminal
```

终端以 UID 1000 运行，并读取 `/etc/mg400/mg400.env`。
程序必须在交互终端中运行。没有终端时，程序退出，退出码为 2。
机械臂地址默认取自 `MG400_ROBOT_HOST`，未设置时取自 `config/robot.toml`。

启动程序不会连接、使能或移动机械臂。
输入 `connect` 后，等待界面显示实测状态。
确认运动范围无人或障碍物后，输入 `enable`。

## 输入命令

输入命令后按 Enter 执行。
用上、下方向键调用历史命令。
用左、右方向键移动输入光标。Home 或 Ctrl+A 移到行首，End 或 Ctrl+E 移到行尾。
Delete 删除光标处的字符，Ctrl+U 清空输入。
输入 `help` 查看命令说明，输入 `status` 查看当前状态。

| 命令 | 行为 |
| --- | --- |
| `connect` | 连接机械臂并取得连接锁 |
| `disconnect` | 请求受控停止并释放控制权。明确下使能并确认后才关闭反馈 |
| `enable` | 使能机械臂 |
| `disable` | 下使能机械臂 |
| `move X Y Z R` | 移动到绝对坐标 |
| `home` | 将 J1–J4 移动到 0° |
| `vacuum suck`、`vacuum release`、`vacuum off` | 吸气、短暂吹气放开部件或关闭吸盘。机械臂必须空闲 |
| `stop` | 请求机械臂受控停止 |
| `status` | 显示当前状态 |
| `help` | 显示命令说明 |
| `quit` | 请求受控停止，确认断开后退出 |
| `quit --force` | 强制退出，不能确认机械臂停止 |

`move` 使用基座坐标系和法兰原点（`User=0,Tool=0`）。
X/Y/Z 单位为 mm，R 单位为度。
执行前，程序用控制器逆解和现有关节范围检查验证目标。
直线运动使用 `SpeedL=1,AccL=1`。
`home` 使用 `SpeedJ=5,AccJ=5`。
`home` 会移动机械臂，不是坐标校准命令。

`status` 和界面显示以下 5 行：

- 机械臂地址和连接状态：`LIVE`、`WAITING / STALE` 或 `DISCONNECTED`。
- `Mode`、`Error`、`Busy` 和 `Locked`。
- `Joints (deg)`：关节 J1–J4。
- `Flange (mm/deg)`：法兰位姿 X、Y、Z 和 R。
- `Vacuum`：`suck`、`blow` 和 `held` 的实测电平。

无新鲜反馈时，测量值显示 `--`。

## 控制吸盘

`stop` 和下使能结束 DO1 的吹气脉冲，保持 DO2 的吸气。
输出说明见 [真空吸盘](development.md#真空吸盘)。

## 停止与退出

输入 `stop` 或按 Ctrl+C，请求机械臂受控停止。
Ctrl+C 后终端保持打开。
停止确认后，输入 `disable`，再输入 `enable` 恢复运动。
受控停止不能代替现场物理急停。
若停止或命令结果无法确认，使用现场物理急停。

输入 `quit` 或按 Ctrl+D，请求受控停止并断开。
确认断开且没有执行中的任务后，终端才退出。
若停止已确认但机械臂仍使能，终端保留反馈连接和连接锁。
终端保持打开，并提示先输入 `disable`，再输入 `quit`。
终端不会自动发送下使能命令。

明确下使能后，服务须取得新鲜的未使能反馈、确认静止，并等候执行中的任务结束，才会断开连接。
这些任务结束前，终端继续等待。
在等待期间按 Ctrl+C，新停止请求可能需要再次手动下使能。
若终端再次提示下使能，输入 `disable`，再输入 `quit`。
正常结束时，先输入 `disable`，再输入 `quit`。
若反馈丢失或无法确认停止，终端保持打开并保留连接锁。
若终端报告停止未确认，使用现场物理急停。

仅在现场物理停止后，使用 `quit --force` 强制退出。
强制退出返回退出码 1，并释放进程锁。
它不能确认机械臂已停止。

进程退出或网络故障时，停止命令可能无法送达。
机械臂可能继续到已发送轨迹的终点。
不要删除锁文件来解除占用。
锁的处理方式见 [面板连接锁](deploy.md#面板连接锁)。
