# 实验室总览

[English](dashboard.en.md)

总览页显示服务状态、当前运行、运行步骤和摄像头链接。
现有可选服务 `orch` 提供此页。参见[部署](deploy.md)和[配方服务配置](orchestrator.md#http-服务)。
使用默认配置时，打开 `http://127.0.0.1:8772/`。
配置 `MG400_ORCH_BASE_PATH` 后，使用对应前缀。可选代理使用 `/lab/`。

## 访问与状态

在 **Access token** 中输入 `MG400_ORCH_TOKEN`，再选 **Connect**。
页面只在内存中保存此令牌。重载页面或选择 **Forget token** 会清除它。
不得把此令牌放入页面 URL。下游服务令牌留在编排服务进程内。

页面外壳及其固定样式和脚本不要求 bearer 令牌。Host 和 Origin 检查仍然有效。
状态和控制 API 要求编排服务令牌。修改请求还必须含 JSON 对象和有效客户端身份。
使用已配置的访问路径。远程访问参见[单端口代理](olares.md#可选的单端口代理)。

各服务卡片显示连接、忙碌、锁定、故障、租约持有者和演示状态。
卡片覆盖机器人、平台、热像仪、视觉服务、炉控和显微镜。
缺失值保持未知。不可用或过期数据不能证明设备正常或已停止。
服务状态超过 3 秒即为过期。轮询失败时，浏览器也把显示内容标为过期。
服务对每台仪器最多同时发起 1 次后台状态读取。

在演示模式下，总览读取不会启动仪器演示。
运行或恢复请求创建自有演示后，对应卡片才可用。
演示模式不使用生产端点和公开摄像头链接。

## 摄像头链接

在服务环境中明确配置摄像头页面 URL：

```sh
MG400_DASH_CAMERA_URL=
MG400_DASH_THERMAL_URL=
MG400_DASH_MICROSCOPE_URL=
```

默认值为空。配置为空时，对应摄像头卡片不可用。
使用可向总览用户公开的 HTTP(S) 页面 URL。浏览器直接打开此页。
不得包含 URL 凭据、仪器 API bearer 令牌、查询参数、片段、空格、控制字符或反斜杠。
总览不会从私有仪器端点推导 URL，也不会转发仪器凭据。
摄像头页面可能要求秘密路径。经认证的总览 API 只返回明确配置的链接。
总览不会发现秘密路径。
摄像头页面仍执行自身的访问规则。

## 停止控制

保持物理急停按钮可触及。网页请求和显示的确认不能充当物理安全联锁。
这些停止操作要求认证，但不要求 **Take control** 或控制租约。
停止操作与运行控制分开：

| 按钮 | 作用 |
| --- | --- |
| **Stop all motion** | 同时向机器人、平台和显微镜分别发出停止请求。它还暂停当前运行并取消恢复。暂停运行也可能停止其已占用的加热、气体和水路输出。 |
| **Heat off** | 必须在页内确认。它取消炉控序列，停止加热及全部炉控气体和水路。它还暂停当前运行并取消恢复。 |
| **Gas off** | 必须在页内确认。它分别请求停止气体通道 `0`、`1`、`2`，不暂停运行。活动序列或配方可能再次供气。炉控故障处理也可能停止其他输出。 |

逐项查看结果。目标状态可能为等待、已确认、未确认、不可用或失败。
停止运动或加热时，首次确认只是暂定结果。服务仍须暂停运行并等待已接受操作结束。
这些操作结束且服务完成最终停止尝试前，新的控制操作保持阻塞。
操作结束后，仍可能有未确认或失败的目标。
不得因某个目标成功或请求获接受，就认定全部运动已停止。
结果未知时，先检查设备并按其恢复流程处理，再继续操作。

## 运行控制与恢复

**Current run** 面板显示运行及其记录的步骤。
选择 **Hold run**、**Resume run** 或 **Abort run** 前，先选 **Take control**。
页面只续期已有租约。续期失败后，必须再次明确选择 **Take control**。
释放或丢失控制权会暂停活动运行并取消恢复。

**Hold run** 停止后续步骤，启动停止和等待清理流程。
**Abort run** 在清理结束后终止运行，但不清除保留的区域占用。
这两种操作都不能证明未知的设备结果安全。

恢复暂停的运行前，先查看记录的步骤状态：

| 步骤状态 | 操作要求 |
| --- | --- |
| 等待中，从未启动 | 不得手动执行此步骤。确认恢复检查通过后将执行此步骤。 |
| 已启动 | 核实物理结果。必要时手动完成步骤，再记录处理结果。恢复会跳过此旧步骤，不会重放。 |
| 未知 | 不得恢复。先解决状态缺失问题。 |

填写非空的 **Resolution note**，再勾选当前步骤对应的确认项。
如果此运行保留区域，核实物理净空并勾选单独的净空声明。
空闲状态本身不能证明物理净空。
服务仍须等待已接受操作结束、确认停止、核对所有权和设备状态。
检查拒绝时，运行保持暂停。

终止运行和保留区域的处理参见[编排恢复流程](orchestrator.md#http-服务)。
总览不会自动恢复已保存运行、重放步骤、重取旧运行租约或清除未知占用。
