# 0005：炉子客户端丢失、重启与关闭

## 状态

已接受：2026-10-30。

## 背景

炉子保温与气体计划可能长于客户端连接。租约到期和进程关闭必须分别处理。

## 决定

保留升温斜坡、HOLD 和保温计时行为。每条命令均执行配置的温度与升温速率上限。

| 条件 | 必须执行的行为 |
| --- | --- |
| 序列步骤开始 | 应用可选的 `gas` 通道百分比表。记录回读值。缺少回读表示未验证，不视为失败。 |
| 任一步骤设置气体 | 序列必须提供 `end_gas` 和 `end_gas_until_c`。 |
| 序列失去控制客户端 | 继续到计划的 STOP/COOLING 结束状态。应用 `end_gas`，直到 PV 低于 `end_gas_until_c`。 |
| 无结束时间的 `apply_setpoint` 失去客户端 | 启动 `MG400_FURNACE_ORPHAN_GRACE_MIN` 计时，默认 15 min。到期后停止加热并应用 `MG400_FURNACE_IDLE_GAS`，默认全部关闭。 |
| 没有客户端持有租约 | 接受停止命令。其他命令等待客户端获取租约。 |
| 启动时读到 RUN 或 HOLD，且持久化状态匹配 | 仅当控制器目标温度差在 2 °C 内时恢复，并记录事件。 |
| 启动时读到 RUN 或 HOLD，但持久化状态不匹配 | 停止加热，应用空闲气体配置，并锁定到人员确认。 |
| 启动时读到 STOP | 保持空闲。 |
| 服务收到 SIGTERM | 停止加热和气体。 |

每次阶段改变及保温期间每隔 60 s，原子写入 `/var/lib/mg400/furnace/state.json`。内容包含步骤、索引、阶段、保温开始的墙上时钟时间、已过时间、气体计划和失去客户端的时间。

序列运行期间，`mg400ctl` 拒绝停止或重启炉子，除非提供 `--force`。操作员提供 `MG400_FURNACE_GAS_MAP` 前，拒绝气体命令。气体映射与工艺默认值由操作员提供。

## 影响

客户端丢失不会中断有界的热处理序列。关闭服务仍会禁用输出。重启状态不确定时必须由人员确认。软件不能替代独立温度保护。
